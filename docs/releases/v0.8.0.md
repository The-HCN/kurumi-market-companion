# v0.8.0 · Windows 便携版

久留美风格的桌面市场助手，支持 A 股、港股、美股行情及财联社快讯，无需配置模型 API。

## 下载与运行

下载 `KurumiMarket-v0.8.0-Windows-x64.zip`，完整解压后双击 `KurumiMarket.exe`。适用于 64 位 Windows，无需安装 Python。请将 `_internal/`、`assets/` 与 EXE 一起保留。

更新前先从托盘退出旧版。需要保留偏好时，将自己的 `settings.json` 和导入音频迁移到新版目录。

## 本版功能

- 财联社市场快讯、A / 港 / 美股指数与自选快照、一次性到价提醒。
- Q 版悬浮人物、平滑弹出气泡、逐字文字、连续嘴型、哭笑表情和眨眼呼吸。
- 单次「叮！」及日语「チャンス！」提示音，可分别试听和调整音量。
- 正文与气泡独立字号，滑块或数字输入支持 12–40 号，推荐 18 / 20 号。
- 系统托盘、单实例、快捷键和消息提醒档位。

已通过 30 项单元测试及便携 EXE 离线自检，验证中文路径、无 Python 环境、托盘、人物气泡、字体设置和音频解码。下载包不含开发者个人设置或原作 PV 录音。

行情为公开快照，可能存在延迟；表情由本地规则驱动。A 股离线交易日历覆盖 2026 年，港股和美股覆盖 2026–2027 年。角色为 AI 绘制同人形象，非官方项目。
