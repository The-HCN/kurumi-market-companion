# 久留美 · 市场陪伴助手 v0.8

Windows 桌面助手，Python 3.10+ / Tkinter / Pillow。无需模型 API 或交易账号。

- A 股、港股、美股指数与自选行情，财联社市场快讯及可选 RSS / Atom 订阅。
- Q 版人物悬浮窗、逐字气泡、连续说话动画和规则驱动的哭笑互动。
- 平滑消息弹窗、短铃声与日语「チャンス！」提示音，支持独立音量。
- 正文与气泡字号可分别用滑块或数字输入调整，支持托盘、快捷键和到价提醒。

v0.8 放大整个面板：正文推荐 18 号、气泡推荐 20 号、按钮 16 号、辅助文字至少 14 号，并提升辅助文字对比度。正文与气泡可分别通过滑块或数字输入调整到 12–40 号，实时预览、自动保存，并可恢复推荐字号。主面板默认 1540×1020，最小 1380×920。保留四指数卡片、单市场紧凑行情条和深色滚动条；来源时间移出正文阅读区。提示音与连续嘴型保持现有设置。`python preview_layout.py` 可用真实数据检查最小窗口、超大字体与市场切换，预览输出到 `artifacts/v8-*.png`。

窗口标题栏与任务栏使用 `assets/kurumi.ico` 久留美头像图标，包含 16–256 像素尺寸。应用使用独立任务栏标识，避免与普通 Python 窗口混在一起；`python build_icon.py` 可从现有素材重新生成图标。

## 启动与体验

### Windows 便携下载版

前往 [Releases 下载 Windows 便携版](https://github.com/The-HCN/kurumi-market-companion/releases/latest)，选择 `.zip` 文件。

`release/KurumiMarket-v0.8.0-Windows-x64.zip` 为 64 位 Windows 便携包。完整解压后双击 `KurumiMarket.exe`，无需安装 Python；不要单独移走 EXE，`_internal/` 与 `assets/` 必须一起保留。详细说明和第三方许可随包提供。更新前退出托盘中的旧版，再迁移自己的 `settings.json` 和导入音频。

压缩包只包含运行文件、当前人物素材、图标、离线日历及两种提示音，不含开发者自选配置、原作 PV 音频、开发环境或项目中的其他文件。附带 `.zip.sha256` 用于校验文件完整性。

构建：`python -m venv .build-venv`，随后用 `.build-venv/Scripts/python.exe -m pip install -r requirements-build.txt` 安装构建依赖，并用该解释器运行 `build_windows.py`。构建输出已存在时不会覆盖，下一次发布应更新版本或移走旧构建。

开发验证入口：`KurumiMarket.exe --self-test-report <输出JSON路径>` 会使用临时配置进行离线界面、托盘、音频和日历自检，自动退出；不修改普通用户配置。

### 从源码启动

双击 `start.bat`，或运行 `python app.py`。如果缺少 Pillow，执行 `python -m pip install -r requirements.txt`。

Windows 启动器优先使用 `pythonw.exe`，不常驻额外控制台窗口。托盘组件可使用本项目 `.runtime/` 中的 pystray，也可通过 `requirements.txt` 安装。

1. 点击人物栏右上角 **演示 ▾ → 上涨 · 笑 / 下跌 · 哭**：体验逐字气泡、说话停顿与短暂哭笑；播报结束约 2.2 秒后恢复平静，闲置时轻微呼吸、间歇眨眼。
2. 点击 **悬浮模式**：拖动人物移动，单击人物显示 / 收起独立气泡。播完默认 8 秒收起；气泡右上角 × 和 Esc 可立即收起。
   鼠标移到人物上显示工具条，双击人物或点击「面板」返回。右键可调整人物大小、暂停播报、关闭自动弹窗，只显示新消息小圆点。
3. 财联社快讯默认开启，启动后自动获取。点击某条消息的「▷ 播报」可重播，点击标题或「详情」查看公开内容，「原文」进入源站。
4. 点击气泡可跳过逐字动画。「消息源设置」可调节打字速度、15 / 30 / 60 秒刷新间隔，开关财联社和指数互动，并补充 RSS / Atom 源。
5. 左侧自选股已接入腾讯公开快照，最多 10 只。点击股票设置一次性到价提醒、取消提醒或预览提醒样式。缺失行情显示 `--`，不会用虚构价格填充。
6. 点击右上角 **字号**，或悬浮人物右键「字体大小…」：正文与详情、人物气泡可分别拖动滑块或输入 12–40 号数字，实时预览并保存。支持输入框上下箭头微调，回车或离开输入框会确认并修正越界值；「恢复推荐字号」设置为正文 18 号、气泡 20 号。旧版标准 / 大号 / 超大号配置会自动转换为相应数字，两处气泡仍可滚动阅读。

## 悬浮消息框

- 大字正文与底部来源 / 时间分开，移除重复的消息前缀。消息框按完整气泡标题预先估算高度，短消息减少空白，长消息限制高度后滚动阅读，逐字时不反复跳动。
- 「查看全文」打开独立详情窗口，展示原消息完整标题或内容；「字号」直接打开字体设置；「固定消息」关闭自动收起，再点一次恢复。固定状态与原有自动收起设置同步保存。
- 标题栏显示播报状态或收起倒计时。鼠标移入会暂停自动收起，移出且播报完成后重新计时；点击正文跳过逐字动画。手动滚动后暂停自动跟随，避免阅读位置被新字顶走。
- 窗口会避让屏幕边缘，保持平滑弹出及不抢焦点；人物工具条加高，更多菜单中可退出。主面板、悬浮人物共用同一个嘴型节奏。

## 行情状态与交易日历

- 指数与自选股分别展示交易状态、数据状态和源站更新时间。交易中、未开盘、午间休市、已收盘、休市与行情连接状态分开显示；休市旧报价显示「最近快照」，交易时段超过 3 分钟的报价显示「数据延迟」。无效或超前时间单独标记。
- 美股按纽约时区判断交易日及夏令时，展示的美股源站时间标记「美东」；A 股与港股标记「北京」。状态按分钟更新，获取新快照后也会刷新。
- `assets/market-calendar.json` 是基于 [exchange_calendars](https://github.com/gerrymanoim/exchange_calendars) 4.13.2 生成的离线交易时段表，包括节假日、午休和已知半日市。A 股使用 XSHG 代表交易日历，覆盖 2026 年；港股 XHKG、美股 XNYS 覆盖 2026–2027 年。超出范围显示「交易日历待更新」，不猜测开市状态。临时停市或个股停牌不由市场日历判断。
- 桌面运行只读取 JSON，不导入 pandas 或联网加载日历。`build_market_calendar.py` 是维护时使用的一次性生成脚本。

## 桌面与提醒

- **系统托盘**：面板右上角 × 收到托盘，继续接收消息；单击托盘图标恢复面板，右键可显示人物、隐藏助手、切换提醒档位或退出。
- **单实例**：重复启动只唤回已有窗口，不再创建第二份。Windows 命名互斥锁和事件负责激活，不占用本地端口。
- **Ctrl+Alt+K**：一键隐藏 / 显示助手，恢复之前的面板或悬浮模式。
- **Ctrl+Alt+M**：打开完整面板。若快捷键被其他程序占用，窗口底部会显示提示，仍可用托盘操作。
- **提醒分档**：「全部消息 / 重要消息 / 仅手动查看」，可在面板右上角、消息源设置和托盘菜单切换。重要消息依据来源的重点标记及真实到价提醒，不调用 AI。切换不影响获取和保存会话内的消息列表；手动点播始终可用。
- **气泡动画**：约 240 ms 淡入并向上滑入，约 160 ms 淡出收起；连续消息和动画反向展开会衔接当前状态。点击 ×、按 Esc 或一键隐藏会立即收起并取消未完成动画。
- 自动气泡不激活窗口，不抢键盘焦点。人物被隐藏时，新消息不会把人物或气泡强行弹回来。

## 消息提示音

右上角「声音」或托盘「消息提示音…」可选择 **普通提示音 / 久留美语音 / 关闭声音**，支持独立音量、试听与停止。不会修改系统音量。

- 普通提示音是单次敲击的短铃声「叮！」，约 0.65 秒，44.1 kHz PCM，本地播放并自然衰减。
- AI 少女声提示音：`assets/audio/chance-ai.wav`，台词「チャンス！」（机会！），已按用户要求恢复上一版（约 0.66 秒，语速 +10%、音调 +45 Hz）。设置中点击「使用 AI『チャンス！』」即可选择。一次生成后离线播放，不影响消息接收，不使用原配音演员的录音。生成参数保存在同名 JSON；一次性生成脚本为 `generate_chance_voice.py`（桌面程序不会调用它）。撤回的清晰版在 `assets/audio/archive/clear-v2/` 中保留。
- 久留美语音播放用户提供的原作片段；在设置中导入 WAV 或 MP3，建议 1–5 秒，每次最多播放 8 秒。导入后复制到 `assets/audio/`，原文件不会改动。
- 先前下载的 [KADOKAWAanime 久留美角色 PV](https://www.youtube.com/watch?v=v-cxfCJlrss) 候选片段保留在 `assets/audio/kurumi-official-pv-preview.wav`，可自行导入。截取 0.50–3.50 秒，台词与语言未人工听辨确认（音轨元数据标记为 en）。来源记录在 `assets/audio/kurumi-official-pv-source.json`。
- 自动播报开始时响一次，遵守提醒档位、暂停和音量设置；自动提示音间隔至少 3 秒，不叠加播放。手动查看消息不重复响铃，「试听」可单独测试。
- Windows 本地音频在独立线程播放，消息获取、气泡和逐字动画不等待音频完成，不调用语音模型。

## 角色与动画

- 依据用户提供的 Q 版参考图生成的久留美同人形象：粉色短发、大头、米色开衫、手持手机。
- 平静、笑、哭三组表情，每组有闭嘴 / 张嘴两帧。开心只轻跳一次，其他时间保持稳定，减少持续抖动。
- 使用新版清理后的素材；在 Windows 透明窗口最终显示尺寸下处理软透明边缘，减少黑边、杂点和毛边。主面板保留平滑透明效果。
- 逐字气泡驱动说话动画，文字完成或点击跳过后停止嘴型。面板与悬浮角色同步。
- 嘴型由独立时钟驱动，约每秒 3–4 次有轻微节奏变化的开合，不随每字或每段文字切换；正文标点处闭嘴停顿，标题标记、来源和时间不做说话动作。文字结束或跳过立即闭嘴，面板与悬浮人物共享节奏。当前是文字播报配套动画，不是完整语音的音素口型同步。自动消息不截断当前内容；手动点播可替换当前内容。
- 空闲时约 3.5–6.5 秒眨眼一次，使用跟随人物位置的矢量眼睑；说话及哭笑时暂不眨眼。约 4.5 秒一个轻微呼吸周期。播报完成或跳过后保留表情约 2.2 秒，再恢复平静；新消息会取消前一条的恢复计时。
- 等待播报最多保留最新三条，排队超过 90 秒跳过自动播报；消息历史仍可手动查看，避免积压越播越旧。
- 表情使用保守关键词规则：明确的上涨消息笑，下跌消息哭；否定、涨跌混杂、通胀等含义不明确的标题保持平静。它不是新闻影响分析或投资建议。
- 这是轻量逐帧动画，不是 Live2D；当前没有语音合成。

## 消息与指数

- **财联社电报**：读取 [公开电报页面](https://www.cls.cn/telegraph) 使用的公开缓存数据，默认每 30 秒刷新，展示宏观、政策、行业及全球市场快讯，不限于个股。首次自动播最新一条；后续最多排入本次新增中的最新三条，列表保留其他消息。
- **公开指数与自选快照**：腾讯公开行情，覆盖上证、恒生、道琼斯、纳斯达克及支持的自选 A 股、港股、美股代码。默认 30 秒更新，指数源站时间原样展示。快照可能延迟或来自前一交易时段，不能视作逐笔行情。
- **指数互动**：只在源站时间距当前不超过 3 分钟、且未获取失败时自动触发；涨幅 ≥ 0.3% 时笑，跌幅 ≤ -0.3% 时哭。切到港股 / 美股页后，使用该市场变化幅度最大的有效指数；「全部」优先 A 股。相同指数至少间隔 120 秒，且涨跌幅较上次互动变化 ≥ 0.3 个百分点才再次触发。
- **到价提醒**：使用真实快照，旧 / 失败 / 时间无效的快照暂停检测，重复时间或倒序数据不触发。有效快照达到目标时只触发一次。旧版演示提醒不会当作真实提醒执行，需在股票详情重新保存。
- **时区**：A 股 / 港股按 UTC+8；美股源站时间按纽约交易所时区并处理夏令时。Windows 使用 `tzdata`。时间无法解析时保守暂停提醒。
- 源站读取失败后按 30、60、120 秒逐步退避，最长 300 秒，手动刷新可提前重试。源站自身更新延迟无法通过加快轮询消除。
- **补充 RSS / Atom**：可选一个 HTTPS 地址，每 5 分钟刷新，保留原文链接。通用快讯显示在所有市场页，不做个股映射或自动翻译。
- 气泡截取长标题并以省略号标记；完整公开内容在「详情」或源站查看，不伪装成 AI 摘要。
- 失败时显示「读取失败 / 未更新」，保留已有消息，不用演示数据冒充真实新闻。来源页面或数据结构变化时可能需要更新适配器。

## 本机数据

`settings.json` 在本机保存自选、提醒、订阅、人物位置与偏好，兼容旧版配置，不随源码或下载包发布。当前人物图集为 `assets/kurumi-sheet-v3.png`。

程序不连接交易账户、不执行下单。从托盘或人物菜单选择「退出」后停止获取消息；关闭面板会继续在托盘运行。没有系统服务或自动开机启动。配置中的订阅 URL 是明文，避免放入敏感凭据。角色为 AI 绘制同人形象，非官方素材。

## 验证

- `python -m unittest discover -s tests -v`：数据解析、来源错误、关键词歧义、到价穿越、配置兼容等。
- `python smoke_test.py`：无网络窗口测试，覆盖逐字进度、嘴型状态、独立气泡收起、自动隐藏、禁用自动弹出、真实提醒拒绝旧快照等；截图在 `artifacts/`，不修改用户配置。
- `python check_live_sources.py`：只读检查真实财联社与指数来源。
- `python preview_live.py`：打开窗口验证实际数据并输出预览，不修改用户配置。
- `python smoke_desktop.py`：Windows 托盘、跨进程重复启动、快捷键指令、提醒分档，以及气泡透明度、位移、焦点、动画反向和取消的集成检查；使用独立实例标识，不修改用户配置。
- `python smoke_sound.py`：声音设置的导入入口、试听参数、音量、保存与提醒策略检查；不实际发声或修改用户配置。
- `python smoke_v6.py`：正文与气泡字号分别即时切换、保存、长文本滚动、表情复位与眨眼状态检查；截图在 `artifacts/v6-*.png`，不修改用户配置。
- `python smoke_mouth.py`：在快、慢逐字速度下采样实际嘴型，检查持续开合、面板与悬浮人物共享节奏，以及跳过时立即停止。
- `python smoke_overlay.py`：短消息完整可见、长消息、来源分离、固定 / 鼠标停留 / 倒计时取消、全文窗口、屏幕边角位置与小人物工具条的检查，截图为 `artifacts/v8-bubble-*.png`。
